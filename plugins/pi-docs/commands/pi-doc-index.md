Generate or update `docs/INDEX.md` — the master registry of all specification documents in the project.

## Procedure

1. **Locate the docs directory.** If $1 is provided, use it. Otherwise, find the `docs/` directory relative to the project root.

2. **Scan all documents.** Inventory every markdown file, feature file, and YAML file in the docs directory tree.

3. **Extract metadata.** For each document, read its YAML frontmatter to extract:
   - Title
   - Status
   - Created date
   - Updated date
   - Authors
   - Tags
   - Links (cross-references)

   For files without frontmatter (like OpenAPI specs), extract the title from the first heading or `info.title` field.

4. **Generate the index.** Write `docs/INDEX.md` with the following structure:

```markdown
---
title: "Document Index"
status: accepted
created: [original creation date or today]
updated: [today's date]
authors: [auto-generated]
tags: [index, meta]
---

# Document Index

> Auto-generated by `/pi-doc-index`. Last updated: [today's date].

## Strategic & Business

| Document | Status | Updated | Authors |
|----------|--------|---------|---------|
| [Title](path) | status | date | names |

## Requirements & Specification

| Document | Status | Updated | Authors |
|----------|--------|---------|---------|
| [Title](path) | status | date | names |

## Architecture & Decisions

### Architecture Decision Records

| # | Title | Status | Date | Links |
|---|-------|--------|------|-------|
| NNN | [Title](path) | status | date | Related docs |

### Requests for Comments

| # | Title | Status | Date | Decision ADR |
|---|-------|--------|------|-------------|
| NNN | [Title](path) | status | date | ADR link |

## Implementation & Operations

### Technical Design Specifications

| Document | Status | Updated | Requirements |
|----------|--------|---------|-------------|
| [Title](path) | status | date | REQ links |

### Executable Specifications

| Feature | Scenarios | Last Updated |
|---------|-----------|-------------|
| [Name](path) | count | date |

### API Contracts

| Service | Format | Updated |
|---------|--------|---------|
| [Name](path) | OpenAPI/GraphQL/Markdown | date |

## Document Health

- Total documents: N
- By status: N accepted, N draft, N review, N superseded, N deprecated
- Last updated range: [oldest] to [newest]
- Coverage: [list of missing core document types, if any]
```

5. If `INDEX.md` already exists, update it in place (preserve the original created date). If it doesn't exist, create it.

6. Report what changed since the last index generation (new documents, status changes, removed documents).
